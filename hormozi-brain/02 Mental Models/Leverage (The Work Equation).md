# Leverage (The Work Equation)


> 🧠 **Core Belief** — foundational to Hormozi's worldview
> work equals outputs and outputs equal volume times leverage

## Description
Getting more output per unit of input. Work is defined as the number of times you do something multiplied by the return on each repetition.

## How to Apply
Order your daily tasks based on the amount of leverage they provide, doing the highest leverage tasks first.
