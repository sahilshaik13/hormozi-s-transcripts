# The Subway Sandwich System

> the reason that subway for example works is because anybody can make a sandwich that tastes the same way if you use the same recipes and use the same process

## The Story
Subway scales massively not because they hire world-class chefs, but because they created a system where literally anyone can make a sandwich that tastes exactly the same by following a strict recipe and process.

## What It Illustrates
To scale a service business, you must decrease the skill requirements of the labor and minimize variability in the output.
